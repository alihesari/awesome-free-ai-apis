# Contribution Guidelines

Thanks for helping keep this list accurate.

## Adding an entry

- The service must offer a real free option: a free tier, free credits, or free models. A paid plan with a free demo page does not count.
- Link to the provider's official pricing or docs page, not a blog post or a third-party review.
- Use this format and keep the section in alphabetical order:

  `- [Name](https://link) - One-sentence description. Free: concise free-tier limit.`

- State only limits the provider publishes. If a number is not on the official page, leave it out.
- One service per pull request, unless the PR updates a whole section.

## Updating an entry

Free tiers change all the time. If a limit changed or a free tier was removed, open a pull request with the link to the official page that shows the change.
